## ⚠️ Modération restrictive — le point le plus important du dossier

Précisions de l'auteur :

- groupe **rejoint tardivement**, comme *MDS all Locations - Forum* ;
- **une seule publication a pu être placée**, sur l'ensemble de la période ;
- échanges occasionnels avec l'une des modératrices, décrits comme « compliqués ».

Conséquence directe sur la lecture : **le facteur limitant de ce canal n'est ni l'audience ni
le texte, c'est l'accès.** Aucun chiffre issu de ce groupe ne dit quoi que ce soit sur la
qualité d'un contenu — il dit ce qu'un unique post autorisé a produit.

C'est le second groupe de l'archive où la modération apparaît explicitement, après *Marathon
des Sables* (« merci à l'équipe d'administration du groupe d'avoir approuvé mes publications,
c'est pas rien 😅 », post du 3 juin). Dans les deux cas, Julien y est un invité sous condition.

**À retenir pour la suite :** dans les groupes MDS — c'est-à-dire ceux dont l'audience est la
plus pertinente pour ce blog — la publication n'est pas libre. Le travail éditorial n'y suffit
pas ; l'accès se négocie.
